- 口に出す：说出口　〔淋しいなんて　口に出したら〕
- 〜なんて：……之类的（带情绪的引用）　〔淋しいなんて　口に出したら〕
- 〜たら：如果……（之后）　〔淋しいなんて　口に出したら〕
- 形容词 て 形：〜い → 〜くて　〔誰もがみんな　うとましくて逃げ出してゆく〕
- 复合动词：逃げる＋出す　〔誰もがみんな　うとましくて逃げ出してゆく〕
- 〜てゆく（回顾）　〔誰もがみんな　うとましくて逃げ出してゆく〕
- 形容词否定：〜い → 〜くない　〔淋しくなんかないと笑えば〕
- 〜なんか＋否定：才不……　〔淋しくなんかないと笑えば〕
- と＋动词：引用　〔淋しくなんかないと笑えば〕
- 〜ば（回顾）　〔淋しくなんかないと笑えば〕
- 形容词く形＋なる：变得……　〔淋しい荷物　肩の上でなお重くなる〕
- なお：更加　〔淋しい荷物　肩の上でなお重くなる〕
- ⚠ 汉字陷阱：荷物　〔淋しい荷物　肩の上でなお重くなる〕
- せめて：退而求其次　〔せめておまえの歌を　安酒で飲みほせば〕
- で：用……（回顾）　〔せめておまえの歌を　安酒で飲みほせば〕
- 复合动词：飲む＋ほす　〔せめておまえの歌を　安酒で飲みほせば〕
- 连浊：さけ → ざけ　〔せめておまえの歌を　安酒で飲みほせば〕
- 长定语，从后往前读　〔遠ざかる船のデッキに立つ自分が見える〕
- 見る ／ 見える　〔遠ざかる船のデッキに立つ自分が見える〕
- 呼唤：名词单独成句　〔歌姫　スカートの裾を〕
- 句子没说完　〔歌姫　スカートの裾を〕
- て 形接下一句　〔歌姫　潮風になげて〕
- 投げる 的画面　〔歌姫　潮風になげて〕
- AもBもCも：……也……也……也　〔夢も哀しみも欲望も　歌い流してくれ〕
- 形容词 → 名词：〜しみ　〔夢も哀しみも欲望も　歌い流してくれ〕
- 〜てくれ：（为我）……吧　〔夢も哀しみも欲望も　歌い流してくれ〕
- 流す：让它流走　〔夢も哀しみも欲望も　歌い流してくれ〕
- 〜に遅れる：没赶上……　〔南へ帰る船に遅れた〕
- 整句是定语　〔南へ帰る船に遅れた〕
- た形作定语＝状态　〔やせた水夫　ハーモニカを吹き鳴らしてる〕
- 〜てる＝〜ている（回顾）　〔やせた水夫　ハーモニカを吹き鳴らしてる〕
- 复合动词：吹く＋鳴らす　〔やせた水夫　ハーモニカを吹き鳴らしてる〕
- 〜にまみれる：浑身沾满　〔砂にまみれた錆びた玩具に〕
- 两个定语叠在一起　〔砂にまみれた錆びた玩具に〕
- 熟字训：玩具＝おもちゃ　〔砂にまみれた錆びた玩具に〕
- ます形词干中顿（回顾）　〔やせた蝶々　蜜をさがし舞いおりている〕
- 々：重复符号　〔やせた蝶々　蜜をさがし舞いおりている〕
- 画面的意思　〔やせた蝶々　蜜をさがし舞いおりている〕
- 〜ように見せる：装成……的样子　〔握りこぶしの中にあるように見せた夢を〕
- 見える ／ 見せる　〔握りこぶしの中にあるように見せた夢を〕
- 整句是定语，核心词是 夢　〔握りこぶしの中にあるように見せた夢を〕
- 疑问词＋〜ばいい：该……才好？　〔遠ざかる誰のためにふりかざせばいい〕
- 名词＋のために：为了……　〔遠ざかる誰のためにふりかざせばいい〕
- ふりかざす　〔遠ざかる誰のためにふりかざせばいい〕
- Aは Bが うまい：A 擅长 B　〔男はいつも　嘘がうまいね〕
- 终助词 ね　〔男はいつも　嘘がうまいね〕
- Aより（も）：比 A 更……　〔女よりも子供よりも　嘘がうまいね〕
- Aが好きだ：喜欢 A　〔女はいつも　嘘が好きだね〕
- 对仗　〔女はいつも　嘘が好きだね〕
- 比较的对象可以很抽象　〔昨日よりも　明日よりも　嘘が好きだね〕
- 熟字训：昨日・明日・今日　〔昨日よりも　明日よりも　嘘が好きだね〕
- 〜気がする：总觉得……　〔遠ざかる船のデッキに　たたずむ気がする〕
- 立つ → たたずむ　〔遠ざかる船のデッキに　たたずむ気がする〕
- もう＋数量：再……　〔もう二年　もう十年　忘れすてるまで〕
- 动词原形＋まで：直到……　〔もう二年　もう十年　忘れすてるまで〕
- 复合动词：忘れる＋捨てる　〔もう二年　もう十年　忘れすてるまで〕

## 6. ヘッドライト・テールライト（headlight-taillight）

- 复合动词：ます形＋动词　〔語り継ぐ人もなく〕
- 定语从句（回顾）　〔語り継ぐ人もなく〕
- 〜もなく：连……也没有，（然后……）　〔語り継ぐ人もなく〕
- 又一个复合动词　〔吹きすさぶ風の中へ〕
- 〜の中へ：往……里去　〔吹きすさぶ風の中へ〕
- 动词连用形中顿：A し、B する　〔紛れ散らばる星の名は〕
- 跨两行的长定语　〔紛れ散らばる星の名は〕
- 名 ／ 名前　〔紛れ散らばる星の名は〕
- 被动 〜られる（回顾）　〔忘れられても〕
- 〜ても（回顾）　〔忘れられても〕
- 省略的主语　〔忘れられても〕
- 外来语：片假名＋长音ー　〔ヘッドライト・テールライト 旅はまだ終わらない〕
- 动词ない形：う段→あ段＋ない　〔ヘッドライト・テールライト 旅はまだ終わらない〕
- まだ＋否定：还没……　〔ヘッドライト・テールライト 旅はまだ終わらない〕
- 降る雨：定语从句　〔足跡は　降る雨と〕

- 行く 读 ゆく　〔行く先を照らすのは〕
